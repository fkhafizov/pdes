How to use this app

Top plot — Recall (Sensitivity) vs Precision at every threshold τ. Each dot is one threshold value; blue labels show τ. The amber marker tracks the active threshold.

Bottom plot — Overall Accuracy as a function of τ. The amber marker moves in sync with the top plot.

Decision Threshold slider — Drag to move the active threshold. Metrics update live: Precision, Recall, F₁, and AUC-PR.

Model Parameters

  • Separation (skill) — spread between positive/negative score distributions. Higher = better classifier, curve bows toward (1, 1).
  • Class imbalance — fraction of positive examples. Affects the random baseline and precision at high recall.
  • Sample size — number of synthetic data points. More = smoother curve.
  • Threshold steps — resolution of the threshold sweep (number of dots on the curve).
  • Beta / Gaussian — score distribution family. Beta concentrates mass near 0 and 1; Gaussian uses clipped normal distributions.

Display Options — toggle threshold labels, dots, random baseline, and AUC fill independently.

Click outside this panel or ✕ to close.

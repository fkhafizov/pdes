    Help

    Map

    The basemap uses OpenStreetMap data rendered by CARTO raster tiles (basemaps.cartocdn.com); the app does not use tile.openstreetmap.org. Choose Voyager for a greener / terrain-style map or Positron (light) for a light basemap. Cell markers are synthetic site placements; each marker shows its cell id under the dot. Popups still include the longer location text.

    Traffic dynamics (not physical UE motion)

    UEs are not drawn moving on the map. The Sankey / alluvial chart uses one selected down A-cell. Columns are times tk = kΔ after outage. First column is traffic still attributed to A; then A → Bi flows from mab(t) = πab(1 − e−t/τ). Between later columns, flows Bi → Bj approximate reshuffling (secondary camping / idle mobility) using a distance kernel on B-sites, with a mass adjustment so each B strip matches the ODE at that time.

    KPIs vs time

    Each B-cell’s KPIs interpolate from baseline to a stressed plateau as the fraction of equilibrium load that has arrived on that B at time t increases (with a mild transient bump). Scoring uses the same t as the time slider / replay. The B-cell KPI time series chart (below Sankey) plots one selected KPI for every B-cell over t = 0…120 min with a vertical cursor at the current slider time — the same timeline as Sankey’s ti = i·Δ (minutes after outage).

    Replay

    Play advances scenario time automatically; Pause stops; Reset time returns to pre-outage. Scrub the slider anytime.

    JSON

    Cells may include lat, lng (degrees) for the map; otherwise legacy x,y in 0–100 are used only for the migration diagram. See prior schema for baseline / plateau.
